# Живая Google Таблица с заявками — настройка (10 минут)

Заявки будут **автоматически** попадать в твою Google Таблицу: новая заявка с сайта/бота
или добавленная вручную в админке — сразу новая строка; изменил статус/оплату — строка
обновится; удалил заявку — строка исчезнет. Никаких выгрузок руками.

Делается через бесплатный Google Apps Script (без Google Cloud, без сервисных аккаунтов).

## Шаг 1. Создай таблицу
1. Зайди на https://sheets.google.com и создай новую таблицу. Назови, например, «АПГРЕЙД — Заявки».

## Шаг 2. Вставь скрипт
1. В таблице: меню **Расширения → Apps Script**.
2. Удали весь код, который там есть, и вставь содержимое файла `google-apps-script.gs` (лежит рядом с этим файлом в проекте).
3. Если хочешь защитить приёмник секретом — впиши любую строку в переменную `SECRET` вверху скрипта (то же значение потом пойдёт в `GSHEET_SECRET`). Можно оставить пустым.
4. Нажми **Сохранить** (значок дискеты).

## Шаг 3. Опубликуй как веб-приложение
1. Справа вверху: **Развернуть (Deploy) → Новое развертывание**.
2. Тип — выбери **Веб-приложение (Web app)**.
3. Настройки:
   - **Запуск от имени (Execute as):** «Я» (твой аккаунт).
   - **У кого есть доступ (Who has access):** «Все» (Anyone).
4. Нажми **Развернуть**, разреши доступ (Google попросит подтвердить — выбери свой аккаунт → «Дополнительно» → «Перейти … (небезопасно)» → «Разрешить». Это нормально, приложение твоё).
5. Скопируй **URL веб-приложения** — он вида `https://script.google.com/macros/s/AKfyc.../exec`.

## Шаг 4. Пропиши переменные в Coolify
В Coolify → приложение **upgrade-2026** → **Environment Variables** добавь:

| Переменная | Значение |
|---|---|
| `GSHEET_WEBHOOK_URL` | URL веб-приложения из шага 3 |
| `GSHEET_VIEW_URL` | ссылка на саму таблицу (из адресной строки, заканчивается на `/edit`) — для кнопки «Открыть» в админке |
| `GSHEET_SECRET` | тот же секрет, что в скрипте (если задавал; иначе не добавляй) |

Сохрани и **передеплой** приложение (Redeploy).

## Шаг 5. Первая выгрузка
1. Открой админку → вкладка **Заявки**.
2. Появятся кнопки **🔄 Синхр. с Google** и **↗ Открыть Google Таблицу**.
3. Нажми **🔄 Синхр. с Google** — все текущие заявки зальются в таблицу.
4. Дальше всё обновляется само.

## Локальный тест (необязательно)
Чтобы проверить у себя на компе — добавь в файл `.env`:
```
GSHEET_WEBHOOK_URL=https://script.google.com/macros/s/.../exec
GSHEET_VIEW_URL=https://docs.google.com/spreadsheets/d/.../edit
# GSHEET_SECRET=твой-секрет   (если задавал)
```
и перезапусти `npm run dev`.

## Если что-то не так
- Кнопки не появились → не задан `GSHEET_WEBHOOK_URL` или не передеплоил.
- «Не удалось связаться с Google Таблицей» → проверь, что веб-приложение опубликовано
  с доступом «Все», и что URL заканчивается на `/exec` (а не `/dev`).
- Строки не обновляются, а дублируются → лист со столбцом `ID` в первой колонке не должен
  переименовываться; скрипт ищет строки по ID именно там.
